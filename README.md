# urban-rotary-Vault
 Study Vault is a secure file management tool for students.
 Select a file, enter a password, and convert it into a protected Vault File. 
 Designed for managing study materials and educational game files while keeping data secure.

# Download
Download StudyVault.exe and run it. No Python installation required.

# Features
Password-protected file storage
Custom Vault File format
Simple Windows interface
Secure file recovery
Student-friendly design

# Important
If you forget the password, the data cannot be recovered. Nobody can get it back, including me.
Don’t leave the vault password somewhere your child can find it, and don’t reuse your Windows PIN.
While the folder is unlocked, it’s a normal folder again. Lock it when you start studying.
Everything is loaded into memory while locking, so it suits study files but not folders of many gigabytes.
Deleted original files can sometimes be recovered with special software on a regular hard drive. For ordinary parental privacy this is fine.
